# JumpCloud Login Assistant 0.4.0 구현·검증 기록

**목표:** 최근 제출 기록에 따른 대기 제한을 제거하고 `https://console.jumpcloud.com/login*`에서 쿼리·해시와 관계없이 자동 실행한다. 기존 GM 계정 저장, 사용자 설정, MFA·오류·부적합 폼 중단과 한 실행 내 반복 클릭 방지를 유지한다.

**설계:** [보안·동작 설계](jumpcloud-login-design.md). JavaScript userscript와 GM API를 사용한다. 제출 시각 기록·Web Locks 의존성은 제거한다. ID/PW의 GM 평문 보관과 소스·Git 분리 계약은 그대로다.

**환경:** Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`, 기존 jsdom 사용, 신규 의존성 없음. 작업 시작 커밋 `667e5fd`, main과 origin/main 0/0, 작업 트리는 깨끗했다.

## 체크포인트 1: 재실행과 URL 제한 제거

**파일:** `jumpcloud-login-assistant.user.js`, `test/jumpcloud-login-assistant.test.js`.

- [x] 최근 비밀번호·이메일 제출 기록 검사, 10분 제한, 제출 시각 저장과 안내를 제거한다.
- [x] localStorage와 Web Locks 의존성을 제거하고 클릭 전에 실행별 제출 단계를 표시한다.
- [x] 정확한 HTTPS 출처와 `/login` 접두사만 검사한다. 쿼리·해시는 조건에서 제외한다.
- [x] 다시 시도는 기록 초기화 없이 현재 페이지에서 즉시 새 실행을 시작한다.
- [x] 기존 제출 기록이 남아 있거나 손상돼도 자동 로그인에 영향을 주지 않는다.
- [x] 임의 URL 파라미터, 새로고침, 이전 기록 관련 핵심 테스트가 변경 전 실패함을 확인한다.
- [x] 새로고침·독립 탭 실행, Web Locks·localStorage 미지원, URL 변경과 반복 이벤트를 검증한다.
- [x] 기존 설정·계정 일치·MFA·수동 제출·입력 취소 회귀를 유지한다.
- [x] 전체 테스트·문법·공백 검사, diff와 실제 자격증명 유입 여부를 검토한다.
- [x] `4aa64a2 feat(jumpcloud): allow login URLs without submission cooldown`으로 커밋·일반 push 후 upstream 0/0을 확인한다.

- [x] 다시 시도, 여러 페이지의 독립 실행과 한 실행 내 중복 방지 범위를 구분한다.

## 검증 증거

| 검사 | 결과 |
| --- | --- |
| JumpCloud 테스트 | 92개 통과. |
| 전체 `npm test` | 190/190 통과. |
| `npm run check` | 두 userscript 문법 검사 통과. |
| `git diff --check` | 공백 오류 없음. |
| 문서 로컬 링크 | 10개 대상 파일 존재 확인. |
| 설치 링크 | 배포된 userscript와 로컬 소스의 바이트 일치 확인. |
| 실제 자격증명 | 사용하지 않음. `.test` 가상 계정만 사용. |
| 실제 계정 E2E | 미실행. 브라우저의 실제 로그인·MFA·포털 진입은 검증하지 않음. |

10가지 로그인 URL, 단계 사이 쿼리·해시 변경, 비밀번호 제출 직후 새 페이지, 독립 탭, 7가지 이전 제출 기록을 검증했다. 테스트의 localStorage 계측은 읽기·쓰기가 한 번이라도 발생하면 실패한다. Web Locks 접근도 차단한다. 이를 통해 이전 기록과 브라우저 API 지원 여부가 실행을 막지 않음을 확인한다.

## 버전 이력

- `0.1.0`: 외부 암호 관리자 자동완성을 원문 접근 없이 진행.
- `0.2.0`: 암호화 GM 저장·사용자 잠금 암호 방식.
- `0.3.0`: 잠금 암호 제거, 평문 GM 저장과 자동 로그인.
- `0.4.0`: 최근 제출 기록에 따른 대기 제한 제거, `/login*`의 쿼리·해시 무관 실행.

기존 `$gcpr` 요청에 따라 검증된 작업 단위마다 명시적 파일 staging과 일반 push를 수행한다. 기존 커밋을 재작성하거나 다른 userscript를 변경하지 않는다. 브라우저 설치·동기화 설정은 변경하지 않았으며 실제 로그인은 수행하지 않았다.
